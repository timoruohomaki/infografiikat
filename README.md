# infografiikat

Tässä repositoriossa on eri käyttötarkoituksiin Claudella tehtyjä infografiikkaelementtejä. Elementit ovat avattavissa draw.io-muodossa.

## Projektin tausta

Repositorion infografiikat tukevat **oikeushallinnon tiedolla johtamisen viitearkkitehtuurin** laatimista. Työn painopiste on johtamisen tuessa, ja graafiset elementit havainnollistavat muun muassa:

- erilaisia johtamisen viitekehyksiä,
- tiedon ja kontekstin roolia johtamisessa,
- viitearkkitehtuurin rakenteita ja niiden välisiä suhteita.

## Käyttötarkoitus ja tekninen toteutus

Kohdedokumentti on **valkoiselle pohjalle taitettu PDF-dokumentti**. Tämän vuoksi graafiset elementit suunnitellaan niin, että niiden kontrasti ja värimaailma toimivat hyvin vaaleaa taustaa vasten ja säilyttävät luettavuutensa myös tulostettuna.

## Sisällön rakenne

| Hakemisto / tiedosto | Sisältö |
|----------------------|---------|
| `*.drawio`           | Lähdetiedostot draw.io-muodossa (muokattavissa) |
| `*.svg` / `*.png`    | Vietävät kuvatiedostot dokumenttiin liittämistä varten |
| `CLAUDE.md`          | Ohjeistus tekoälyavustajalle infografiikoiden tuottamiseen |
